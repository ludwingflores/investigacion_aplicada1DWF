DESCRIPCION:
El proyecto utiliza un un modelo Empleado para poder trabajar con el y mostrar los diferentes estados de una entidad utilizando EntityManager y el contexto de persistencia. Tambien se utiliza la capa servicio
para los diferentes metodos y la capa controlador para poder realizar las request utilizando Postman.
